## 📊 Project Preview
[Dashboard Preview](pro3.png)


## 📌 Business Overview
Manual record keeping in pharmacies often leads to high human error and significant financial loss due to expired stock. This project provides a comprehensive digital blueprint for transforming manual workflows into an automated, error free system.

## 🚀 Business Value
* **Risk Mitigation:** Real time alerts for expiring medicine prevent legal risks and financial wastage.
* **Operational Efficiency:** Streamlines the billing and checkout process, reducing customer wait times.
* **Stock Visibility:** Provides management with instant data on current inventory levels across different categories.

## 📁 Key Artefacts Included
* **Business Requirements Document (BRD):** Defining functional and non functional needs.
* **UML Diagrams:** Use Case and Activity diagrams for process clarity.
* **User Stories:** Defining the end user journey for pharmacists and managers.
