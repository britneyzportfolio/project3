# Pharmacy Inventory Management: UI/UX Wireframe & Logic

## 🎯 Objective
This project focuses on designing the user interface and inventory logic for a pharmacy management system. The primary goal was to create wireframes that streamline the manual inventory tracking process, ensuring an intuitive experience for staff to manage stock levels and monitor expiry dates effectively.

## 🛠 Tech Stack
* **UI/UX Design & Wireframing:** Draw.io (Mockups & Flowcharts)
* **Logic Modeling:** Mermaid.js (Data Flow Diagrams)
* **Documentation:** Microsoft Word/PDF (Functional Specifications)
* **Version Control:** GitHub

## 📊 Visuals

## 🔑 Key Features
* **Inventory Dashboard Wireframe:** Designed a clean user interface to provide a snapshot of current stock and critical alerts.
* **Streamlined Data Entry Flow:** Created wireframes to simplify the process of adding new stock and updating inventory data.
* **Expiry & Stock Logic:** Defined the logical workflow for flagging items reaching expiry or low-stock thresholds.

## 📈 Business Impact
* Simplified complex inventory tasks into a user friendly digital interface.
* Reduced the learning curve for staff by creating intuitive UI flows.
* Provided a clear blueprint for developers to understand the inventory management requirements.

## 💡 Key Learnings
* **UX/UI Design for Business:** Learned how to transform manual business processes into efficient digital wireframes.
* **Prototyping Skills:** Gained experience in designing user flows that prioritize usability and data accuracy.
* **Bridging the Gap:** Developed the ability to communicate functional requirements to stakeholders through visual wireframes.
